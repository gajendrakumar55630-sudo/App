# ApnaVibe

A mobile-first social sharing app prototype built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser to try it.

## Features

- Home feed with sample photo posts, likes, and comments
- Reels page with short video examples
- Photo/video upload preview and local post creation
- Demo registration/login flow and editable profile
- People search, follow buttons, and notifications
- Responsive bottom navigation for mobile

## Run locally

No build step or dependencies are required. Open `index.html` directly, or serve this directory with any static web server.

> This first version is a front-end demo: account data, posts, followers, and notifications are not connected to a backend. Demo login does not authenticate or securely store passwords. Uploaded posts exist only for the current browser session.
